# Diagrams

| File | Use |
|---|---|
| `catalog-structure.drawio` | The source of the catalog diagram in [apps/boutique/catalog](../../apps/boutique/catalog/README.md). Open it in draw.io and edit it. |
| `catalog-structure.svg`, `catalog-structure.png` | The same diagram as images. A script drew them from the same coordinates as the `.drawio` file, with plain boxes and simple curves. The names and links come from `org.yaml` and `catalog-info.yaml`. After an edit of the `.drawio` file, export new images from draw.io. The PNG is 2x with a white background. |
