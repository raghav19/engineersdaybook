# Diagrams

| File | Use |
|---|---|
| `architecture.drawio` | The source of the architecture diagram in the [README](../../README.md). Open it in draw.io and edit it. |
| `architecture.svg`, `architecture.png` | The same diagram as images. A script drew them from the same coordinates as the `.drawio` file, with plain boxes and simple curves. After an edit of the `.drawio` file, export new images from draw.io. The PNG is 2x with a white background. |
