# Diagrams

| File | Use |
|---|---|
| `agent-workload-identity.drawio` | The source of the diagram in [workload-attestation.md](../workload-attestation.md). It shows the server with its entries and the host SPIRE agent. The agent has the Delegated Identity API, the `msbvm` plugin and the `unix` attestor. It also shows the delegate, the VMM with the microVM, and `msb.db`. A flow panel below the diagram repeats the steps in words. |
| `agent-workload-identity.svg`, `agent-workload-identity.png` | The same diagram as images. A script drew them from the same coordinates as the `.drawio` file. After an edit of the `.drawio` file, export new images from draw.io. The PNG is 2x with a white background. |
