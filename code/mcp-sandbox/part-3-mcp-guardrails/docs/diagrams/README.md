# Diagrams

| File | Use |
|---|---|
| `architecture.drawio` | The source. Open it in draw.io and edit it. |
| `architecture.drawio.svg` | The same diagram as an image. GitHub renders it, and draw.io can edit it. |
| `orchestration.drawio` | The source of the Flux orchestration diagram in [orchestration.md](../orchestration.md). |
| `orchestration.drawio.svg` | The same diagram as an image, with the source embedded. |
| `rendered-manifest-without.drawio` | The source of the "without rendered manifests" diagram in [rendered-manifest-pattern.md](../rendered-manifest-pattern.md). |
| `rendered-manifest-with.drawio` | The source of the "with rendered manifests" diagram in the same document. |
| `rendered-manifest-flow.drawio` | The source of the workflow flow diagram in the same document. |
| `rendered-manifest-without.png`, `rendered-manifest-with.png`, `rendered-manifest-flow.png` | The same diagrams as images. A script drew them, with simple icons that look like the draw.io icons. The `.drawio` files use the real draw.io icons. After an edit, export the PNG files from draw.io again. |
| [`../images/rendered-manifest-linkedin.png`](../images/rendered-manifest-linkedin.png) | The without and with diagrams and the screenshot of the pull request comment in one image, for a post. It is the three images, scaled and not changed. |
