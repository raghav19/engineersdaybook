# Diagrams

| File | Use |
|---|---|
| `architecture.drawio` | The source. Open it in draw.io and edit it. |
| `architecture.drawio.svg` | The same diagram as an image. GitHub renders it, and draw.io can edit it. |
| `orchestration.drawio` | The source of the Flux orchestration diagram in [orchestration.md](../orchestration.md). |
| `orchestration.drawio.svg` | The same diagram as an image, with the source embedded. |
| `orchestration.png` | The same diagram as a 2x image with a white background, for a post. |
| `app-of-apps.drawio` | The source of the app-of-apps diagram: the root applies 3 groups, and each group manages its units. |
| `app-of-apps.svg`, `app-of-apps.png` | The same diagram as images. A script drew them from the same coordinates as the `.drawio` file, with plain boxes. After an edit of the `.drawio` file, export new images from draw.io. The PNG is 2x with a white background, for a post. |
| `rendered-manifest-without.drawio` | The source of the "without rendered manifests" diagram in [rendered-manifest-pattern.md](../rendered-manifest-pattern.md). |
| `rendered-manifest-with.drawio` | The source of the "with rendered manifests" diagram in the same document. |
| `rendered-manifest-flow.drawio` | The source of the workflow flow diagram in the same document. |
| `rendered-manifest-without.png`, `rendered-manifest-with.png`, `rendered-manifest-flow.png` | The same diagrams as images. A script drew them, with simple icons that look like the draw.io icons. The `.drawio` files use the real draw.io icons. After an edit, export the PNG files from draw.io again. |
| `node-attestation.drawio` | The source of the node attestation diagram in [zero-trust-node-attestation.md](../zero-trust-node-attestation.md): the host script asks the SPIRE server for a join token and an alias, and the agent in the microVM joins the server. |
| `spire-setup.drawio` | The source of the setup diagram in the same document: how Flux, kind, the host script, the dev-tools kit and the SPIRE agent fit together. |
| `node-attestation.svg`, `spire-setup.svg` | The same diagrams as images. A script drew them from the same coordinates as the `.drawio` file. After an edit of the `.drawio` file, export new SVG files from draw.io. |
| `workload-attestation.drawio` | The source of the workload attestation diagram in [zero-trust-workload-attestation.md](../zero-trust-workload-attestation.md): `spire.py` registers the Envoy entry under the alias, and the agent gives Envoy its SVID. |
| `workload-attestation.svg`, `workload-attestation.png` | The same diagram as images. A script drew them from the same coordinates as the `.drawio` file. After an edit of the `.drawio` file, export new images from draw.io. The PNG is 2x with a white background. |
| [`../images/rendered-manifest-linkedin.png`](../images/rendered-manifest-linkedin.png) | The without and with diagrams and the screenshot of the pull request comment in one image, for a post. It is the three images, scaled and not changed. |
| [`../images/node-attestation-linkedin.png`](../images/node-attestation-linkedin.png) | The node attestation diagram, the setup diagram of the SPIRE server and agent, and a flow of the join in one 2x image for a post. A script drew it from the same model as the `.drawio` files, and the flow panel has no `.drawio` source. |
| [`../images/app-of-apps-linkedin.png`](../images/app-of-apps-linkedin.png) | The app-of-apps diagram above two screenshots of the Flux Operator UI (Managed Objects, Graph) for a post: the root `flux-system`, and the group `gateway`. The `gateway` screenshot is cropped above the list of its seven sources. The raw screenshots are `../images/app-of-apps-flux-root.png` and `../images/app-of-apps-flux-gateway.png`. |
