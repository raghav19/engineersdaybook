# Diagrams

| File | Use |
|---|---|
| `backstage-architecture.drawio` | The source of the architecture diagram in [backstage-idp.md](../../research/backstage-idp.md): frontend, backend, data and the systems outside Backstage. |
| `backstage-architecture.svg`, `backstage-architecture.png` | The same diagram as images. A script drew them from the same coordinates as the `.drawio` file. After an edit of the `.drawio` file, export new images from draw.io. The PNG is 2x with a white background. |
| `catalog-entity-life.drawio` | The source of the catalog diagram in the same document: how a descriptor file becomes an entity that plugins read. |
| `catalog-entity-life.svg`, `catalog-entity-life.png` | The same diagram as images. A script drew them from the same coordinates as the `.drawio` file. After an edit, export new images from draw.io. The PNG is 2x with a white background. |
| `scaffolder-workflow.drawio` | The source of the template diagram in the same document: one Software Template run from the wizard to its three outputs. |
| `scaffolder-workflow.svg`, `scaffolder-workflow.png` | The same diagram as images. A script drew them from the same coordinates as the `.drawio` file. After an edit, export new images from draw.io. The PNG is 2x with a white background. |
| `idp-target-platform.drawio` | The source of the platform diagram in the same document: what runs in the msb VM, on the host and outside, and what the sandbox blocks. |
| `idp-target-platform.svg`, `idp-target-platform.png` | The same diagram as images. A script drew them from the same coordinates as the `.drawio` file. After an edit, export new images from draw.io. The PNG is 2x with a white background. |
