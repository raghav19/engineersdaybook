# Diagrams

| File | Use |
|---|---|
| `architecture.drawio` | The source of the architecture diagram. It shows the host, the sandbox container with its relay, the Unix socket, the systemd socket unit with `systemd-socket-proxyd`, iron-proxy, the Bitwarden project and the allowed hosts. |
| `architecture.svg`, `architecture.png` | The same diagram as images. After an edit of the `.drawio` file, export new images from draw.io. The PNG is 2x with a white background. |
