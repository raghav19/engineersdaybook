# Diagrams

| File | Use |
|---|---|
| `architecture.drawio` | The source of the first diagram. It shows the host, the sandbox container, the host services (iron-proxy and the socket bridge), the Bitwarden project and the allowed hosts. |
| `network-flow.drawio` | The source of the second diagram. It shows the steps of one request from the agent to an allowed host. |
| `architecture.svg`, `architecture.png`, `network-flow.svg`, `network-flow.png` | The same diagrams as images. After an edit of a `.drawio` file, export new images from draw.io. The PNG is 2x with a white background. |

The README of this folder's parent still describes the krun design. It links these diagrams after the rewrite.
